# 部署到公网 + iPhone 添加到主屏幕

> 目标：手机任意网络都能打开，桌面有图标，点开全屏，能离线刷题。
> 成本：**0 元**。不用 Mac，不用开发者账号，不用打包。

---

## 一、先生成部署包

```bash
cd mobile
node scripts/prepare-deploy.js
```

生成 `quiz-app/dist/` 目录（91MB，5377 个文件）。
这个目录就是你要上传的全部内容。

**已自动清理的冗余**：
- 调试页面（diag.html / minimal.html）
- 旧版 JS（zhenti.js / law.js / papers.js，已被 -v5 版本取代）
- 开发备份（*.full_backup）
- 乱码的 manifest.webmanifest

---

## 二、部署到公网（三选一）

### 方案 A：Netlify Drop（最简单，免注册即可试）

1. 打开 https://app.netlify.com/drop
2. 把 `dist` 文件夹**直接拖进网页**
3. 等 30 秒 ~ 2 分钟（91MB 上传取决于网速）
4. 得到一个地址，形如 `https://xxx-yyy-zzz.netlify.app`

**优点**：不用注册就能先试。想要固定地址再注册（免费）。

⚠️ 首次上传 91MB 可能较慢，请耐心等进度条。

### 方案 B：Cloudflare Pages

1. 注册 https://dash.cloudflare.com （免费）
2. 左侧 **Workers & Pages** → **Create** → **Pages** → **Upload assets**
3. 项目名随意，上传 `dist` 文件夹
4. 得到 `https://项目名.pages.dev`

**优点**：全球 CDN 快，免费流量无上限。

### 方案 C：GitHub Pages（如果你能访问 GitHub）

1. 把 `dist` 内容推到仓库（可用 `gh-pages` 分支）
2. 仓库 Settings → Pages → 选分支
3. 得到 `https://用户名.github.io/仓库名/`

⚠️ 你那边 GitHub 网页访问超时，这个方案可能不适合。

---

## 三、iPhone 添加到主屏幕（核心步骤）

部署完成后，得到一个 `https://` 开头的地址。接下来：

### 1. 用 Safari 打开（必须 Safari，不能是 Chrome）

> iOS 上只有 Safari 能把网页添加到主屏幕。

### 2. 点底部分享按钮

屏幕底部中间，方框带向上箭头的图标。

### 3. 选「添加到主屏幕」

在分享菜单里往下滑，找到这个选项。

### 4. 确认名称，点「添加」

默认会用 `manifest.json` 里的 `short_name`（「真题刷题」）。

### 5. 完成

桌面出现图标，点开是全屏运行（没有 Safari 地址栏）。

---

## 四、验证离线可用

添加到主屏幕后，测试离线：

1. 先联网打开 App 一次（让 Service Worker 缓存资源）
2. 等页面完全加载
3. 开飞行模式
4. 从桌面图标打开 App
5. **应该能正常刷题**

如果不能离线，检查：
- 是不是用 Safari 添加的（Chrome 添加的不带 SW）
- 第一次打开时是否加载完整（题库 19MB 需要时间）

## 五、关于「分享给别人」

如果想让别人也能用，直接把那个 `https://` 地址发给对方：

- 对方用 Safari 打开
- 同样「添加到主屏幕」

**不需要打包，不需要签名，不需要审核。**

⚠️ 注意：这是「网页应用」不是「App Store 应用」。
如果对方期待在 App Store 里搜到，那做不到（需付费开发者账号 $99/年 + 审核）。

## 六、更新内容后怎么重新部署

改了代码后：

```bash
cd mobile
node scripts/prepare-deploy.js
```

然后把 `dist` 重新拖到 Netlify / Cloudflare。

**提示用户刷新**：可以改一下 `site/index.html` 里的 `VER` 变量，
页面顶部的「检测到新版本，请按 Ctrl+F5 刷新」提示会自动出现。

⚠️ 已添加到主屏幕的用户，SW 更新需要**关闭 App 再打开**两次才会生效。

## 七、91MB 是不是太大

**主要由题目配图占用**：

| 类型 | 数量 | 大小 |
|------|------|------|
| PNG | 4233 | 23.7 MB |
| JPG | 901 | 23.6 MB |
| WebP | 194 | 14.3 MB |
| JSON | 15 | 19.1 MB |
| JS | 31 | 10.6 MB |

**能不能压缩？**

- 图片已大部分是 WebP/JPG，进一步压缩会损失清晰度
- 免费托管方案对体积不敏感（Netlify 100GB/月流量，Cloudflare 无限）
- 首次加载会慢一些，但 SW 缓存后就不用了

**如果觉得太慢**，可以只部署行测 7 科，去掉法律题库（`data/zt/law.js` 6MB）
和套卷图片。先改 `site/index.html` 里的菜单，再生成 dist。

## 八、常见问题

### 拖拽上传卡住

91MB 文件较多（5377 个），Netlify Drop 处理需时间。
如果超过 10 分钟没动静，改试 Cloudflare Pages。

### 手机打开白屏

1. 确认用的是 `https://` 不是 `http://`
2. 等 5-10 秒（首次加载题库慢）
3. 检查地址末尾有没有多余路径

### 添加到主屏幕后图标是默认的

说明 `manifest.json` 或图标路径有问题。确认：
- `dist/manifest.json` 存在
- `dist/icons/icon-192.png` 和 `icon-512.png` 存在
- Safari 需要 `apple-touch-icon`，检查 `dist/icons/apple-touch-icon.png`

### 离线打不开

- 确认第一次是联网完整加载的
- iOS 的 Safari 对 SW 缓存有配额限制，91MB 可能超出
- 如果超限，离线只会有部分内容。这种情况下建议：
  - 减少部署体积（去掉大图片）
  - 或接受「必须联网使用」

### 想用自己的域名

Netlify / Cloudflare 都支持绑定自定义域名（免费方案也可以）。
需要有个域名（约 ¥30/年）。

## 九、和「打包成 ipa」的对比

| 项目 | 静态托管 + 主屏幕 | 打包 ipa |
|------|------------------|---------|
| 成本 | 0 元 | 云构建免费，但签名需 Apple 账号 |
| 需要 Mac | ❌ 不需要 | ✅ 需要（或用云构建） |
| 安装难度 | 5 分钟 | 2 小时 |
| 有效期 | **永久** | 免费签名 7 天 |
| 能否分享 | ✅ 发链接即可 | ❌ 只能自己设备 |
| App Store | ❌ 不能上架 | 需 $99/年 + 审核 |
| 离线 | ✅ 能 | ✅ 能 |
| 原生能力 | ❌ 无推送/震动 | ✅ 有 |

**自己用 → 选静态托管。要上架 → 必须是 ipa + 付费账号。**
