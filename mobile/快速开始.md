# iOS App 打包 —— 一页速查

## 最快路线（推荐先看这个）

### ① 只想手机上有个图标点开就用 → PWA（5 分钟）

iPhone 用 **Safari** 打开你的站点 → 点底部分享 → **添加到主屏幕** → 完成。

有图标、全屏、可离线。**不需要打包，不需要 Mac。**

---

### ② 想要真正的 App → 云构建 + 侧载（1-2 小时，纯 Windows 可行）

**第一步：云构建拿到 .ipa**（在本项目里已配置好）

注册 https://codemagic.io（免费 500 分钟/月）→ 关联 Gitee 仓库 →
设置工作目录 `mobile/` → 构建命令：
```
npm install
npm run sync
cd ios/App && pod install && cd ../..
```
→ 下载产出的 `.ipa`

**第二步：Windows 上签名安装**

1. 下载 https://sideloadly.io/
2. iPhone 数据线连电脑
3. 把 `.ipa` 拖进 Sideloadly
4. 填你的 Apple ID（免费账号即可）
5. 点 **Start**
6. iPhone 上信任证书：设置 → 通用 → VPN与设备管理 → 信任

⚠️ 免费 Apple ID 签名的 App **7 天后失效**，每月需重签几次。
⚠️ 需要电脑装 iTunes（Sideloadly 靠它识别设备）。

---

### ③ 有 Mac → 直接编译（最正规）

```bash
# 在 Mac 上
cd mobile
npm install
npm run sync
cd ios/App
pod install
open App.xcodeproj
```

Xcode 里：
1. 选 **Signing & Capabilities**
2. Team 选你的 Apple ID（免费的就行）
3. Bundle Identifier 改成唯一的（如 `com.你的名字.zhenti`）
4. 连 iPhone，按 `Cmd + R`

## 日常改代码后

网页改了以后，在这个目录运行：

```bash
npm run sync
node scripts/verify-www.js
```

或者双击 **`打包iOS.cmd`**（Windows，一键构建+自检）。

然后重新编译。

## 常见问题

**Q: 云构建出来的是未签名 ipa，能用吗？**
A: 不能直接装。必须用 Sideloadly / AltStore 签名，或用付费开发者账号。

**Q: 7 天限制怎么破？**
A: 三个办法：① 付费开发者账号（$99/年，签名 1 年有效）
② 用 AltStore 自动重签（需家里有台常开的电脑）
③ 用 PWA 方案，没有失效问题

**Q: 能不能上架 App Store？**
A: 技术上可以，但注意 Apple 审核指南 **4.2 条**：
「只是把网页包一层」的 App 容易被拒。需要证明原生价值。

**Q: Windows 真的完全没法编译吗？**
A: 对。iOS 编译必须用 Xcode，Xcode 只有 macOS 版。
虚拟机装 macOS 理论可行但违反 Apple 协议，且极不稳定。

**Q: 92MB 是不是太大了？**
A: 主要是因为题库里有大量原书扫描图（WebP）。
上架前可以压缩图片，能降到 40MB 左右。只是自用的话不用管。
