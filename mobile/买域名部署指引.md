## ⚠️ 先看这段：关于备案

**指向 Cloudflare（境外）的域名无法完成 ICP 备案**，因为备案要求域名解析到国内有资质的服务器。

所以这条路的性质是「未备案域名 + 境外 CDN」：

| 项目 | 现实情况 |
|------|---------|
| 技术可行性 | ✅ 可以访问（你的网络能打开 cloudflare.com 后台，说明 CF 的 IP 段可达） |
| 合规性 | ⚠️ 理论上属未备案，有极小被拦风险 |
| 风险程度 | 低。个人自用、不传播、不做推广，基本不会被处理 |

**如果你要求完全合规**，改走这条路：
1. 买阿里云/腾讯云轻量应用服务器（约 ¥60/年起）
2. 域名备案（免费，管局审核 1-20 天）
3. 部署到国内服务器

总成本约 ¥100/年，慢但合规。告诉我，我改配这套。

## 第 1 步：买域名（10 分钟，¥14）

1. 打开 https://buy.cloud.tencent.com/domain
2. 搜索框输入你想要的名字，比如 `zhenti-你的名字`
3. 后缀选 **`.top`**（首年 ¥14，续费 ¥34/年，是所有后缀里续费最便宜的）
4. 加入购物车 → 结算 → 支付

### 完成实名认证

腾讯云要求域名实名：

- 人脸识别
- 通常 **即时通过**（最长 1-2 天）

⚠️ 未实名认证的域名会被暂停解析。

## 第 2 步：Cloudflare 添加站点（5 分钟，免费）

1. 打开 https://dash.cloudflare.com （注册免费账号，用邮箱即可）
2. 顶部 **Add a site**（或 Add domain）
3. 输入你刚买的域名（如 `xxx.top`）
4. 套餐选 **Free**（免费版）
5. Cloudflare 会自动扫描现有 DNS 记录（可能找不到，正常）
6. **跳过/继续**，最后会给你两个 NS 地址：

```
xxxx.ns.cloudflare.com
yyyy.ns.cloudflare.com
```

**把这两个地址复制下来**，下一步要用。

---

## 第 3 步：修改 DNS 服务器（在腾讯云后台，3 分钟）

1. 腾讯云 → 控制台 → **域名与网站** → **我的域名**
2. 找到你的域名 → 点 **管理**
3. 左侧 **DNS 修改**（或「DNS服务器」）
4. 把默认的 DNSPod 地址改成 Cloudflare 给的那两个
5. 保存

**等待生效**：通常 10 分钟 ~ 2 小时，最长 24 小时。

验证方法（在电脑命令行运行）：
```bash
nslookup -type=NS 你的域名
```
看到 `ns.cloudflare.com` 就说明生效了。

## 第 5 步：绑定你的域名（5 分钟）

1. Pages 项目 → **Custom domains** 标签
2. **Set up a custom domain**
3. 输入你的域名（如 `zhenti.top`）
4. Cloudflare 会自动添加 CNAME 记录
5. 点 **Activate domain**
6. 等 1-5 分钟

完成后访问 `https://你的域名` 应该就能打开。

## 常见问题

### 上传卡住

91MB / 5377 个文件比较多。如果 10 分钟没动静：
- 检查网络
- 或改用 **Wrangler CLI** 上传（更快）：

```bash
npm install -g wrangler
cd quiz-app/dist
wrangler pages deploy . --project-name=zhenti
```

### DNS 改了但还是打不开

- 等更久（最长 24 小时）
- 用 `nslookup 你的域名` 看解析到哪个 IP
- 如果解析到 Cloudflare IP（104.x / 172.67.x）但打不开，说明域名被墙，需要换方案

### Cloudflare Pages 域名被墙怎么办

你现在的网络无法访问 `*.pages.dev`（我之前测过）。如果绑了自定义域名也被墙：

**换方案**：
1. 用国内服务器（阿里云轻量 ¥60/年）+ 备案
2. 或者继续用离线单文件版

### 备案能不能做

不能。域名指向境外服务器时，管局会驳回备案申请。要么用国内服务器，要么不备案。

### 续费会不会涨价

`.top` 续费稳定在 ¥34/年。注册时可以在腾讯云后台提前续几年，锁定价格。
