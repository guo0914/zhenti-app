# 行测刷题 · 分类真题 + 资料分析

带账号体系、分类刷题与计时功能的行测刷题系统。

- **分类真题**：来自 [ERRRC/xingcezhenti](https://github.com/ERRRC/xingcezhenti) 的 2023–2026 年国考 + 省考真题，
  按 政治理论 / 常识判断 / 言语理解与表达 / 数量关系 / **图形推理** / 判断推理 / 资料分析 分类，
  含官方解析。图形推理从「判断推理」中单独拆出。
- **资料分析套题**：`C:\Users\严睿霖\Desktop\疯狂刷2500题-资料分析600题_...pdf` 扫描件（Windows OCR），600 题 30 套，附原书截图。
- **后端**：`server.py`（Python 标准库 `http.server` + `sqlite3`，零依赖）
- **前端**：`site/`（原生 HTML/CSS/JS，无框架、无构建）
- **数据库**：`quiz.db`（SQLite，自动创建）

## 分类刷题怎么用

左侧 **分类刷题** → 选模块 → 选每组题数（5/10/15/20/30/50 或自定义 1–100）
→ 选限时（不限时 / 5–30 分钟）→ 选随机或顺序 → 开始练习。

七个分类，共 **5461 道真题**（2023–2026 国考 + 省考，50 套卷）：

| 分类 | 题数 | 卷数 |
|---|---|---|
| 政治理论 | 382 | 49 |
| 常识判断 | 664 | 49 |
| 言语理解与表达 | 1278 | 46 |
| 数量关系 | 664 | 48 |
| **图形推理** | 424 | 48 |
| 判断推理 | 1232 | 48 |
| 资料分析 | 817 | 47 |

- 图形推理从「判断推理」中单独拆出；其余判断推理题目（类比/定义/逻辑）保留在「判断推理」里
- 每题都带**官方解析**，答完即可展开
- 资料分析题自带「材料 N」+ 图表，材料文字可展开
- 顶部计时可暂停；限时到点自动交卷
- 错题自动进错题本（与资料分析套题共用同一个错题本）
- 每组练习记录写入 `drills` 表（分类、题数、完成数、正确数、用时）

## 启动

双击 **`启动.cmd`**，浏览器会自动打开。

或用命令行：

```powershell
cd quiz-app
python server.py --port 8000 --open
```

**想让手机也能用**：双击前先确认手机和电脑在同一 WiFi，然后在该目录打开命令行执行
`启动.cmd --lan`（或 `python server.py --host 0.0.0.0 --port 8000 --open`），
手机访问 `http://电脑内网IP:8000/`，详见下方「手机 / 平板使用」。

首次打开会要求**注册账号**（用户名 3–20 位中文/字母/数字，密码至少 6 位）。
注册后自动登录，所有数据写入 `quiz.db`。

> **端口**：默认 8000；若被占用会自动向后顺延（最多试到 8011），实际地址以启动窗口显示为准。
> 换端口：`python server.py --port 8080 --open`
> 服务默认监听 `0.0.0.0`（本机 + 局域网都可访问），启动窗口会打印本机内网 IP。

## 手机 / 平板使用

界面已做移动端适配（窄屏自动收起侧栏为抽屉菜单，答题卡移到题目下方，选项触控高度 45px），
但**服务必须跑在电脑上**——它是 Python + SQLite，手机浏览器打不开 `.py` 文件。

### 场景一：电脑和手机连同一个 WiFi（最简单）

1. 双击 `启动.cmd`（默认已监听 `0.0.0.0`）
2. 看启动窗口打印的「局域网访问」地址，例如 `http://192.168.1.21:8000/`
   （也可以自己查：`ipconfig | findstr /i "IPv4"`）
3. 手机浏览器打开该地址，注册/登录即可

**防火墙**：Windows 防火墙默认拦截入站连接。本机已存在放行 `python.exe` 的规则（Public 配置），
且当前 WiFi 属于 Public 网络，实测可访问。换到 Private 网络或换机器时，若手机打不开：

- 首次启动时 Windows 可能弹「是否允许 Python 访问网络」，选**允许**（专用 + 公用都勾）
- 或手动放行（管理员 PowerShell）：
  ```powershell
  New-NetFirewallRule -DisplayName "ZLFX Quiz" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow
  ```

**加到主屏幕**：手机浏览器菜单里选「添加到主屏幕」，就能像 App 一样从桌面直接打开。

**注意**：`--host 0.0.0.0` 会监听所有网卡，同一局域网内的设备都能访问，账号体系是本地的、
也没有 HTTPS，仅适合家庭/个人网络，不要在公共 WiFi 下长期开着。

### 场景二：电脑和手机在不同 WiFi / 手机用流量（跨网络）

电脑在 `192.168.1.x` 这类内网、且没有公网 IP 时，手机在别的网络**无法直接连进来**，
需要内网穿透。两种方案：

**方案 A：Cloudflare Quick Tunnel（已内置脚本，免费、无需注册、无需公网 IP）**

1. 先正常启动刷题服务：双击 `启动.cmd`（保持服务窗口开着）
2. 再双击 **`穿透.cmd`**（首次会自动下载 cloudflared，约 55MB，之后秒开）
3. 脚本窗口会显示一个 `https://xxx.trycloudflare.com` 地址
4. 手机（无论什么网络）浏览器打开该 https 地址即可访问

注意：
- 该 https 地址**每次启动会变**，断开后需要重新看新地址
- 免费即时隧道无服务保证，若提示 `409 / provisioning failed` 说明当前不可用，改用方案 B
- 关闭 `穿透.cmd` 窗口即断开穿透，不影响本机服务

**方案 B：Tailscale（点对点虚拟局域网，最稳定，推荐）**

1. 电脑安装 [Tailscale](https://tailscale.com/download) 客户端并登录（用任意邮箱/Google/微软账号）
2. 手机应用商店安装 Tailscale App，登录**同一个账号**
3. 两边都开启后，电脑会得到一个 100.x.x.x 的虚拟 IP（Tailscale 客户端里可见）
4. 手机浏览器打开 `http://<电脑的100.x.x.x>:8000/` 即可访问

优点：地址固定、无需公网 IP、不依赖第三方免费隧道配额；缺点：手机和电脑都要装客户端。

> 无论哪种方案，穿透期间手机和电脑共用同一个 `quiz.db` 数据库，进度一致。

## 账号与数据

**密码安全**：PBKDF2-HMAC-SHA256，16 万轮迭代，每个用户独立 16 字节随机盐；比对用 `hmac.compare_digest` 常数时间。
数据库里只有哈希与盐，没有明文密码。

**会话**：登录后发放 32 字节随机令牌，有效期 30 天，存 `sessions` 表；请求带 `Authorization: Bearer <token>`。
退出登录即删除该令牌。

**数据归属**：每个用户的作答、错题、收藏、计时全部按 `user_id` 隔离，查询带 `WHERE user_id = ?`。

### 数据库结构（`quiz.db`）

| 表 | 作用 | 关键字段 |
|---|---|---|
| `users` | 账号 | `username_key` 唯一索引（小写查重）、`pass_hash`、`pass_salt` |
| `sessions` | 登录令牌 | `token` 主键、`expires_at` |
| `answers` | 每题作答 | 主键 `(user_id, qid)`，含 `sel`、`ok`、`secs`（本题用时） |
| `marks` | 收藏 | 主键 `(user_id, qid)` |
| `wrongs` | 错题本 | `wrong_count`、`cleared`、`fixed`、`last_ts` |
| `sets_time` | 每套计时 | `elapsed`、`limit_secs`、`submitted`、`submit_ts` |
| `day_stats` | 每日汇总 | 主键 `(user_id, day)`，`n` / `ok` / `secs` |
| `question_log` | 作答流水 | 每次作答追加一行，可回溯历史 |

启用 WAL 模式，外键级联删除；删除用户会自动清空其全部数据。

## 计时功能

**每套独立计时**，进入某套题即开始累计，切换套题自动切换计时器。

- **不限时**（默认）：正计时，显示累计用时与平均每题用时
- **限时**：可选 10 / 15 / 20 / 30 / 45 分钟，倒计时，最后 1 分钟变红
- **暂停 / 继续**：暂停期间时间冻结，适合中途走开
- **自动交卷**：倒计时归零自动交卷并弹出统计
- **手动交卷**：未答完会先确认；统计含完成数、正确率、本套用时、平均每题时长、错题数

**每题用时**也单独记录：从进入该题到选中选项的秒数，存在 `answers.secs`，错题与统计里都会显示。

计时每 10 秒同步一次服务器，切换页面/关闭浏览器时再落一次，避免丢失。

**关于 OCR 精度**：题目文字是机器识别结果，个别数字/符号可能失真（如 `1` 被识别成 `L`、`15` 成 `巧`）。
因此：

- 每题都保留原书截图，随时点「查看原题截图」对照；
- 172 道题被标记为「建议对照截图」，默认直接展开原图，选项退化为 A/B/C/D 字母，按原图作答即可，判定照常；
- 已做高置信度清洗（`巧→15`、数字中的 `L→1`、区间连接符、全角符号等），其余可疑字符一律不猜，交给原图。

## 功能

**账号**
- 注册 / 登录 / 退出，令牌自动续用（30 天）
- 登录时自动合并本地与服务器进度（取较新者），换浏览器不丢
- 清空进度会同时清服务器数据

**答题**
- 逐题作答，选完即时判定（可在 ? 里关掉）
- 键盘：`A/B/C/D` 选答、`←/→` 翻题、`空格` 对答案、`F` 收藏、`R` 重做、`M` 资料文字、`T` 暂停计时
- 答题卡实时标对错与当前位置；资料可收起，可展开 OCR 文字
- 每题显示该题用时

**错题本**
- 答错自动收录，记错误次数与最后作答时间
- 「顺序重练」「随机 10 题」跨套专项模式
- 答对后不自动移除，需手动「移出」

**收藏**：一键收藏，可连续演练、可导出 JSON

**题库速查**：按题号/题干/选项/答案检索，支持「仅错题」

**学习统计**
- 已作答、正确率、答题累计用时、平均每题用时、错题/收藏数
- 近 7 天练习量（来自服务器 `day_stats`，换设备也在）
- 耗时最多的套题 Top 5、错题集中套数
- 30 套完成度热力图 + 每套计时明细
- 导出进度 / 清空进度

**题库导入**
- 拖拽或选择文件，支持 JSON 与 CSV，也可粘贴文本
- 可在内置题库与自建题库之间切换（自建库存浏览器本地）

**其它**：深浅色主题、移动端响应式、打印样式

## 重建题库

生成脚本在工作区的 `.pdfwork/`：

```powershell
# 1. 先把原始 PDF 复制为 .pdfwork\book.pdf，然后 PDF → PNG + OCR（约 3 分钟）
powershell -ExecutionPolicy Bypass -File .pdfwork\ocr.ps1 -Start 1 -End 221 -SavePng

# 2. 解析答案页 + 组装题目 + 切片原图
python .pdfwork\build_final.py

# 3. OCR 文本清洗、标记可疑题、输出 data/bank.js
python .pdfwork\normalize.py
```

需要 Python + Pillow；OCR 用 Windows 自带的 `Windows.Media.Ocr`（不需要 tesseract）。

## 真题抓取与解析

题库不是手工录入的，而是从开源仓库抓取后解析：

```powershell
cd quiz-app

# 1) 抓取 markdown（分段，配额耗尽会自动等待）
python fetch_loop.py

# 2) 解析成结构化题库 → site/data/zhenti.json + zhenti.js
python parse_zhenti.py
```

**为什么需要分段抓**：GitHub 未登录 API 每小时只有 60 次配额，
而本机到 `raw.githubusercontent.com` 的 TCP 握手要 8 秒以上（几乎不可用），
只有 `api.github.com` 稳定。`fetch_loop.py` 会在配额耗尽时自动等到重置再继续。

`manifest.json` 是各分类的文件清单（含年份、大小），用于筛选目标卷子。
默认只抓 `国家公务员 / 联考 / 山东 / 江苏 / 浙江 / 广东 / 四川` 七类，
覆盖国考与主要省考；要抓全量改 `fetch_loop.py` 里的 `KEYWORDS` 为空即可。

**解析规则**（`parse_zhenti.py`）：

- 题目块以 `## 第 N 题　<sub>qid xxx · 二级分类</sub>` 开头
- 选项格式 `- **A**. 内容　✅`（✅ 标记正确答案）
- `**答案**：X` 与 `**官方解析**` 之后为答案和解析
- 判断题（选项写作 `- （选项）[]`）补成「A 正确 / B 错误」两选项
- 图片路径保留原仓库相对路径，暂未本地化（图形推理题需图片，见下）

## 已知限制

- **图形推理 / 资料分析图表题依赖图片**：图片用 `fetch_images_parallel.py` 抓取，
  速度受网络限制（约 0.06 张/秒）。未下载完的图片位会显示「图片待下载」占位，不会破图；
  文字类题目（政治/常识/言语/数量/判断-文字题）完全不依赖图片。
- 真题是「网友回忆版」，个别题干表述与官方原卷可能有差异。
- 抓取受 GitHub 配额限制：文字题已全量到手，图片仍需再跑若干轮 `fetch_images_parallel.py`。
- 172 题扫描版资料分析因 OCR 数字失真标记为「建议对照截图」，选项显示为字母，需按原图形作答。
- 服务默认只监听 `127.0.0.1`；局域网共享用 `--host 0.0.0.0` 并自行评估风险。
